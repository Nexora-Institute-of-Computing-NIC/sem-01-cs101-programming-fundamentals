# CS101 — Programming Fundamentals — PLAN

**Semester:** 1 · **Credits:** 4 · **Level:** Beginner
**Theory:** 45 hrs · **Lab:** 30 hrs · **Language:** C

## Syllabus

### Unit 1 — Introduction to Programming (9 lectures)
1. What is a program
2. Computational thinking — decomposition, patterns, abstraction, algorithms
3. From source code to running program
4. The compilation pipeline (preprocess → compile → assemble → link)
5. Anatomy of your first C program
6. Variables, data types, and operators
7. Constants, printf format specifiers
8. Reading input with scanf
9. Type conversion and common beginner mistakes

### Unit 2 — Control Flow (9 lectures)
1. The if statement and truthiness in C
2. if / else if / else chains
3. Nested conditionals and dangling-else
4. The switch statement and fall-through
5. Ternary operator
6. while loops
7. for loops
8. do-while and when the body must run first
9. break, continue, nested loops

### Unit 3 — Functions and Modular Design (9 lectures)
1. Why functions — reuse, naming, testability
2. Anatomy of a function: signature, parameters, return
3. void functions
4. Pass-by-value and its consequences
5. Function prototypes and header files
6. Multi-file projects with .c and .h
7. Include guards
8. Scope: local, global, static
9. The three-file pattern for projects

### Unit 4 — Arrays and Strings (9 lectures)
1. Declaring, initialising, traversing arrays
2. Bounds — off-by-one and undefined behaviour
3. Common array patterns (max, count, search, reverse)
4. Two-dimensional arrays and row-major layout
5. Strings as null-terminated char arrays
6. Reading strings safely with fgets
7. strlen, strcpy, strncpy, strcat, strcmp
8. Passing arrays to functions — pointers in disguise
9. Buffer overflow and safe-copy idioms

### Unit 5 — Pointers, Structs and Files (9 lectures)
1. What a pointer is and what it stores
2. & address-of and * dereference
3. NULL pointers and defensive checks
4. Pass-by-pointer to modify caller variables
5. Pointer arithmetic and iterating arrays
6. Heap memory: malloc, calloc, realloc, free
7. The five classic pointer bugs
8. struct, typedef, pointers-to-struct and ->
9. File I/O: fopen, fgets, fprintf, fclose

## Practical Labs (19)

1. Environment setup and Hello World
2. Unit converter (km/mi, C/F, kg/lb)
3. Grade calculator with input validation
4. Patterns and multiplication tables with nested loops
5. Prime number toolkit (is_prime, count_primes, nth_prime)
6. Marks analyser (mean, median, max, min)
7. Palindrome and word counter
8. Pointer-based array reversal
9. Student record system using structs
10. Persistent to-do list with CSV file
11. Matrix operations: add, multiply, transpose
12. Safe string utilities library
13. Recursive functions practice (factorial, Fibonacci, GCD)
14. Menu-driven banking simulation
15. Text file word-frequency counter
16. Simple singly-linked list in C
17. Binary / decimal converter
18. Sorting algorithm comparison (bubble, insertion, selection)
19. Sudoku validator

## Assignments

1. Variables and arithmetic — temperature, circle, digit sum
2. Conditionals and loops — leap year, Fibonacci, FizzBuzz
3. Functions and arrays — array statistics, string utilities, matrix transpose
4. Pointers, structs, files — pointer swap, dynamic array, CSV reader
5. Final project — Personal Finance Tracker with rubric
